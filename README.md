# FAZILA & FAYAZ — THEIR PERSONAL NETFLIX-STYLE LOVE STORY
> *"A love story that never stopped streaming."*

A bespoke, production-grade, Netflix-inspired private memory platform built as a birthday surprise from a wife (Fazila) to her husband (Fayaz).

---

## 🌹 Design Identity & Visual Atmosphere

Inspired by premium streaming architectures and private memory archives:

- **Midnight Plum**: `#100D19` — Deep atmospheric backdrop
- **Deep Wine**: `#321627` — Rich cinematic accent
- **Muted Berry**: `#762D4A` — Emotional warmth & badge highlights
- **Champagne Gold**: `#C99B72` — Shimmer typography & accents
- **Warm Ivory**: `#F2E8DD` — Crisp, legible reading text
- **Dusty Rose**: `#C98A9C` — Romantic secondary tone
- **Typography**: Cormorant Garamond / Cinzel for emotional headings, Plus Jakarta Sans for interface.

## 🚀 Running Locally & Deployment

### Local Development
```bash
npm run dev
```
Open `http://localhost:3000` in your browser.

### Production Build
```bash
npm run build
```
Generates a verified, self-contained `dist/` directory ready for deployment.

### Vercel Deployment
Configured with `vercel.json` for SPA rewrites and asset caching:
1. Push repository to GitHub or run `vercel` CLI.
2. Vercel automatically detects the build command and serves from `dist`.
